### commit message 编码陷阱（再次踩 LRN-013/014 同类问题）
- `git commit -m "中文"` 经 PS 传参时，UTF-8 字节被 PS 当 UTF-16 LE 处理，导致 commit message 写入 git 后是 UTF-16 LE mojibake
