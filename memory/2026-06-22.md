## 12:30 markitdown vs ppt-master 转换能力对比（重要结论）

**结论：入库 RAG 只能用 ppt-master，不能用 markitdown。**

### 实测对比（同一文件：罗兰贝格2025中国汽车全球化发展报告.pdf）

| 指标 | markitdown | ppt-master pdf_to_md.py |
|------|------------|------------------------|
| 总字符 | 19,931 | 11,787 |
| 标题层级(# ## ###) | 无 | 有（H1=40pt/H2=24pt/H3=22pt 按字号推断） |
| Markdown 表格 | 完全散掉，每格一行无法还原 | 规范 \| 分隔 Markdown 表格 |
| 页码标记 | 无 | 有 <!-- Page N --> |
| 列表/加粗 | 无 | 有 **加粗内容** |

### ppt-master 支持的转换格式（source_to_md 目录）

| 脚本 | 格式 | 结构保留能力 |
|------|------|------------|
| pdf_to_md.py | PDF | 标题+表格+列表+页码，按字号推断层级 |
| doc_to_md.py | DOCX/HTML/EPUB/IPYNB（原生）| 标题+表格+列表 |
| doc_to_md.py | DOC/ODT/RTF/TeX（pandoc fallback）| 需安装 pandoc |
| excel_to_md.py | XLSX/XLSM | Markdown 表格 |
| ppt_to_md.py | PPTX | 标题+表格+列表+超链+备注 |
| web_to_md.py | 网页/微信 | 需 curl_cffi |

### Python 环境要求

| 工具 | Python 版本 | 状态 |
|------|-----------|------|
| ppt-master pdf_to_md.py | 需要 Python 3.10+ | notebook-6.5.7 = 3.11.9 可用 |
| markitdown | 任意版本 | notebook-6.5.7 可用 |
| car_agent_env | Python 3.9.7 | 不支持 ppt-master（语法不兼容） |

**正确运行方式**：必须用 E:\AI\data\envs\notebook-6.5.7\python.exe 跑 ppt-master 脚本。
